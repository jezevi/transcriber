# TransCheck

Маленькая программа для Windows: **проверяет расшифровку, которую вы набрали сами**.

Что программа **не делает**: не слушает аудио, не расшифровывает за вас, не нажимает кнопки и не вводит ответы на странице задания, не ходит в интернет. Текст она получает только тогда, когда вы сами его скопировали (`Ctrl+C`). Это не проверка орфографии: слово с ошибкой она не заметит, если слова нет в её таблицах.

Для другого задания, «Транскрибации речи с английским 3 stage» (два поля, другие правила), эта версия не подходит: набор правил для него ещё не добавлен.

## Как это работает на практике

1. Вы слушаете запись и печатаете расшифровку в поле задания, как обычно.
2. Выделяете текст в поле и копируете: `Ctrl+A`, затем `Ctrl+C`. В окне TransCheck текст появляется сам, ошибки подсвечены.
3. Нажимаете `Ctrl+Alt+J` (или кнопку «Исправить безопасное и скопировать»): программа исправляет механические ошибки и кладёт результат в буфер обмена.
4. В поле задания: `Ctrl+A`, затем `Ctrl+V`. Остальные замечания из списка (числа, латиница, смех, заикание) решаете сами: двойной щелчок по строке применяет предложение, если оно есть.

Отметки в задании («В записи присутствуют иностранные слова», «Есть речь, которую невозможно транскрибировать») программа не ставит: их ставите вы. Памятка про них есть внизу окна (нажмите на её заголовок, чтобы свернуть или развернуть; на невысоком экране она свёрнута сама).

### Что значат цвета

| Цвет | Что это | Что делать |
|---|---|---|
| Синий («Исправится само») | Механическая правка: регистр, знаки, «ё», слова из таблицы. | Ничего, её сделает кнопка «Исправить безопасное». |
| Красный («Исправить вручную») | Нарушение, которое программа сама не исправляет: числа, латиница, мат со звёздочками. | Исправьте вы. Если у замечания есть предложение, двойной щелчок по строке его применит. |
| Жёлтый («Проверить») | Подозрение: смех, заикание, «ток/тока». Это может оказаться правильным. | Послушайте запись и решите сами. |

Цвет строки в списке и цвет подсветки в тексте одинаковые. Выбранное замечание в тексте подчёркнуто, а цветная полоса слева от пояснения показывает его тип.

## Как получить программу (.exe)

Программа собирается на GitHub автоматически, так же, как ScreenFix.

1. Создайте новый репозиторий на GitHub (лучше **Private**).
2. **Add file → Upload files**: перетащите всё содержимое этой папки, кроме папки `.github` (веб-загрузка GitHub её пропускает). Нажмите **Commit changes**.
3. **Add file → Create new file**, имя файла: `.github/workflows/transcheck-build.yml`. Вставьте текст из файла `.github/workflows/transcheck-build.yml` этой папки и нажмите **Commit changes**.
4. Вкладка **Actions** → **TransCheck build** → **Run workflow**. Обычно через 2–3 минуты сборка станет зелёной.
5. Откройте запуск, внизу в разделе **Artifacts** скачайте `TransCheck-windows`, распакуйте в любую папку (например, `C:\TransCheck`).

## Первый запуск

1. Запустите `TransCheck.exe`. Откроется окно. Крестик сворачивает окно, программа остаётся работать. Полностью закрыть: кнопка **Выход** или `Ctrl+Alt+Q`.
2. Нажмите **Самопроверка**: она покажет, работают ли правила на примерах из инструкции, буфер обмена и слежение за ним на вашем компьютере.
3. Windows может показать «Система Windows защитила ваш компьютер» (программа не подписана): **Подробнее → Выполнить в любом случае**. Антивирус иногда ложно ругается на программы, собранные PyInstaller.
4. Проверьте на простом примере: напишите в Блокноте `Привет, Мир! Щас позвони +7 900 123 45 67`, выделите всё и скопируйте (`Ctrl+A`, `Ctrl+C`). В окне должны появиться четыре замечания: «Привет,», «Мир!» и «Щас» (исправятся сами) и номер телефона (предложение словами, применяется двойным щелчком). Кнопка «Исправить безопасное» даст `привет мир сейчас позвони +7 900 123 45 67`. Орфографические ошибки («хател», «пре») программа не ищет: это не проверка правописания.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| `Ctrl+Alt+K` | Взять текст из буфера обмена и показать окно (нужно, если выключен автоподхват). |
| `Ctrl+Alt+J` | Исправить всё безопасное и скопировать результат в буфер обмена. |
| `Ctrl+Alt+Q` | Выйти из программы. |

Программа не нажимает клавиши за вас: `Ctrl+A`, `Ctrl+C` и `Ctrl+V` в браузере нажимаете вы. Если сочетание занято другой программой, TransCheck скажет об этом при запуске: поменяйте клавишу в `config.json`.

## Что проверяется

«Само» значит, что исправление входит в «Исправить безопасное». Остальное только подсвечивается, предложение (если есть) применяется двойным щелчком по строке.

| Что | Раздел | Как |
|---|---|---|
| Заглавные буквы | 1 | само |
| Знаки препинания, кавычки, скобки, дефисы (дефис заменяется пробелом, как в «че то») | 1 | само |
| «ё» → «е» | 1 | само |
| Лишние пробелы, переносы строк, невидимые символы, знаки ударения | 1 | само |
| Латинские буквы-двойники внутри русского слова («пpивет» с латинской p) | 1 | само |
| Таблица-шпаргалка: «щас» → «сейчас», «наверно» → «наверное», «типо» → «типа», «кешбек» → «кэшбэк», «тыща» → «тысяча», «алё» → «алло» и другие | 2, 4, шпаргалка | само |
| Слова с частью «сбер» слитно («сберпэй», «сбербизнес»…), составные слова («маткапитал», «физлицо»…) | 11, 12 | само |
| Иностранные слова из таблицы кириллицей («youtube» → «ютуб», «pdf» → «пдф», «the» → «зе»…) | 10, шпаргалка | само |
| Мат: варианты написания из таблицы («блядь» → «блять», «на хуй» → «нахуй»…) | 15 | само |
| Мат со звёздочками | 15 | подсветка |
| Цифры и символы: нужно словами. Предложение в именительном падеже (проверьте падеж и род) | 9 | подсветка + предложение |
| Латиница: 1–2 слова — «пишите русскими буквами и ставьте галочку»; 3+ слов подряд — «фраза или строчка песни: поле пустое и отметка» | 10 | подсветка |
| Смех («ха ха ха»), звуки-паразиты («эээ», «ммм»), распевы («ла ла ла», «ооо») | 7, 13, 14 | подсветка + предложение «убрать» |
| Заикание: повтор слога («по по пошел», «ска сказал») | 5 | подсветка + предложение «убрать» |
| Слова «ток» и «тока» (в шпаргалке — «только», но бывают и верными) | шпаргалка | подсветка + предложение |

Программа сверяет текст только с правилами, которые перечислены выше. Всё, что зависит от того, **что слышно на записи**, остаётся за вами: обрывки слов, оговорки с исправлением, говор и акцент, фоновая речь, речь не на русском, пение и песни на фоне, «пик» вместо мата, пропущенные слова.

## Свои правила (`rules_extra.txt`)

Инструкция меняется (последний раз 28.10.2026), а программа об этом не узнает. Поэтому рядом с программой лежит файл `rules_extra.txt` (кнопка **Свои правила**). Одна строка — одно правило:

```
как не надо => как надо
по тихому => потихому
```

Регистр, «ё» и знаки в правилах не учитываются. Строки с `#` не читаются. Правила начинают работать сразу после сохранения файла, перезапускать программу не нужно, и они сильнее встроенных. Если в строке ошибка, окно скажет, в какой.

Если инструкция изменилась сильно, лучше обновить программу: пришлите новый текст инструкции.

## Настройки (`config.json`, лежит рядом с программой)

| Поле | По умолчанию | Зачем |
|---|---|---|
| `hotkey_check`, `hotkey_fix`, `hotkey_quit` | `ctrl+alt+k`, `ctrl+alt+j`, `ctrl+alt+q` | Горячие клавиши. Формат: `ctrl+alt+k`, допускаются ctrl, alt, shift, win и латинская буква, цифра, F1–F12. Менять можно, перезапуск нужен. |
| `watch_clipboard` | `true` | Подхватывать текст, как только вы его скопировали. Если `false`, текст берётся клавишей `Ctrl+Alt+K`. |
| `topmost` | `true` | Окно поверх остальных. |
| `max_chars` | `5000` | Длиннее этого текст не подхватывается (защита от случайно скопированной страницы). |

## Важно знать

- **Проверяйте результат глазами.** Исправление механическое, но оно не знает смысла: например, дефис в слове заменяется пробелом, как в таблице («че то»), а что делать со словом в вашем случае, решаете вы.
- **Окно работает с тем текстом, который в нём сейчас.** Если вы поправили расшифровку в браузере уже после копирования, скопируйте её заново (`Ctrl+A`, `Ctrl+C`), иначе исправление и вставка возьмут старый вариант.
- **Числа.** Предложение «сорок пять» строится в именительном падеже без учёта окончаний: «в двадцать первом году» программа не напишет. Падеж и род по смыслу правите вы.
- **Мат** в таблице исправляется так, как это записано в инструкции. Если слова нет в таблице, оно не меняется.
- **Автоподхват работает на любое копирование.** Если вы скопировали что-то не из задания, в окне появится это. Чтобы не мешало, снимите галочку «Подхватывать текст при копировании» и пользуйтесь `Ctrl+Alt+K`.
- **Буфер обмена.** Если включена история буфера (`Win+V`), в ней остаются и ваш исходный текст, и исправленный.
- **Правила площадки.** В условиях Toloka запрещены боты, скрипты и ИИ-агенты, которые сами выполняют задания (международные условия, раздел 2.1.3). TransCheck ничего не вводит и не отправляет на странице задания: расшифровку набираете вы, а программа только сверяет её с инструкцией. Тем не менее перед использованием убедитесь, что условия вашей площадки и заказчика допускают такие вспомогательные программы.

## Если что-то не работает

| Что происходит | Что делать |
|---|---|
| Текст не появляется в окне после `Ctrl+C` | Проверьте галочку «Подхватывать текст при копировании». Либо нажмите `Ctrl+Alt+K`. Если окно было активным, когда вы копировали, текст не подхватывается (чтобы не подменять то, что вы набираете). |
| «В буфере обмена нет текста» | Скопирована картинка или файл. Выделите именно текст в поле. |
| «Горячая клавиша … уже занята» | Поменяйте её в `config.json` и запустите программу снова. |
| «Файл rules_extra.txt не читается (нужна кодировка UTF-8)» | В Блокноте: Файл → Сохранить как → Кодировка: UTF-8. |
| Окно не помещается на экране | Растяните или переместите его; размер подстраивается под экран при запуске. |
| Программа не запускается | Рядом с ней появится файл `transcheck_crash.log`. Пришлите его. |

Автозапуск с Windows: `Win+R` → `shell:startup` → положите туда ярлык на `TransCheck.exe`.

## Что проверено автоматически, а что нет

Проверено тестами (в том числе на сборке с настоящим Tk): правила на всех примерах «неправильно → правильно» из инструкции, устойчивость исправления на тысячах случайных текстов (результат не содержит запрещённых знаков, повторное исправление ничего не меняет), числа словами, слежение за буфером и горячие клавиши на заглушке Windows, окно с подсветкой при масштабе 100 % и 150 %, самопроверка.

**Не проверялось без вашего компьютера:** настоящий буфер обмена и горячие клавиши Windows, поведение в браузере с вашей страницей задания, шрифты и вид окна на вашем экране, ввод `Ctrl+C/V` в русской раскладке в самом окне. Первое покажет кнопка «Самопроверка», остальное — первый запуск.

Оконные тесты запускаются ещё и на Windows при сборке на GitHub (шаг «Tests (windows and orchestration on real Tk)»). Если этот шаг оранжевый, значит, часть оконных тестов не прошла на сборщике, а программа при этом всё равно собирается.
